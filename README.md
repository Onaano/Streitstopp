# Streit-Stopp – Konflikte erkennen & Lösungen finden

Browser-Lernspiel für die Grundschule (Klasse 2–4) aus der Reihe **Förderfreude Games**.
Leitfrage: **„Was könnte jetzt helfen?"** – nicht „Wer hat Schuld?".

## Starten
`index.html` im Browser öffnen. Das Spiel besteht aus **einer einzigen Datei** und läuft ohne Internet.
Für GitHub Pages oder Netlify die Datei unverändert hochladen.

## Die vier Bereiche
| Bereich | Frage | Fälle |
|---|---|---|
| Streit-Check | Was wissen wir wirklich? (drei Schritte: Wissen → Vermuten → Und jetzt?) | 14 |
| Streit-Regler | Was macht den Streit größer oder kleiner? | 16 |
| Lösungsfinder | Was könnte jetzt helfen? (Mehrfachauswahl) | 16 |
| Sag's anders | Klar sagen, was du meinst. | 14 |

Eine Runde hat 8 zufällig gezogene Fälle. Keine Punkte, keine Zeit, kein Game over.
Die vier Schritte **STOPP – SCHAU – SAG – LÖSUNG** begleiten das Spiel.
Hilfe holen wird in passenden Fällen ausdrücklich als sinnvoll gezeigt („kein Petzen").

## Technik
- Reines HTML/CSS/JavaScript, alle Figuren und Szenen als Inline-SVG
- Keine Frameworks, externen Schriften, Bilder, APIs, Cookies, Tracking oder LocalStorage
- Responsiv von 320 bis 2560 px; Touch, Maus und Tastatur; sichtbare Fokusrahmen; `prefers-reduced-motion`
- Vorlesen (Sprachausgabe de-DE) nur auf Knopfdruck; ohne Stimme bleibt das Spiel voll spielbar

## Inhalt dieses Pakets
- `index.html` – das Spiel
- `arbeitsblaetter/Streit-Stopp_Stundenentwurf.pdf` – Stundenentwurf (2 Seiten, 45 Minuten)
- `arbeitsblaetter/Streit-Stopp_Arbeitsblatt.pdf` – 1 Blatt beidseitig für die Kinder (ohne Lösungsblatt)
- `pruefung/testbericht.md` – durchgeführte Tests und bekannte Grenzen

## Hinweis
Die Sprachausgabe hängt vom Gerät ab. Die Lösungsbewertungen sind pädagogische Vorschläge, keine absoluten Antworten.
